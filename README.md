Referensi Desain: https://ulanbuana.com/
Project ini terinspirasi dari desain website Ulan Buana Engineering dengan beberapa penyesuaian.
Modifikasi yang dilakukan meliputi perubahan identitas perusahaan menjadi JaeConstruction, penyesuaian warna dan tampilan agar lebih modern,
penambahan beberapa section seperti HSE dan Team, serta penambahan fitur interaktif seperti filter project, validasi form, dan dark mode menggunakan JavaScript dan jQuery.
----------
manipulasi DOM
1. Project Filter
   Pada bagian “Our Projects”, saya menambahkan fitur filter project menggunakan JavaScript. User dapat memilih kategori       seperti “All”, “Construction”, dan “Engineering”. Saat tombol dipilih, website akan menampilkan project sesuai kategori     dan menyembunyikan project lainnya secara otomatis sehingga tampilan menjadi lebih interaktif dan memudahkan pengguna       melihat jenis project tertentu.
   ![alt text](https://github.com/muhammadyaaqin24-art/UTSWeb_4B_0002/blob/main/pict/pic2.png?raw=true)
   ![alt text](https://github.com/muhammadyaaqin24-art/UTSWeb_4B_0002/blob/main/pict/pic3.png?raw=true)

2. Form Validation
   Pada bagian contact form, saya menggunakan JavaScript untuk melakukan validasi input. Sistem akan mengecek apakah           seluruh field seperti nama, email, dan pesan sudah diisi sebelum form dikirim. Jika masih ada data yang kosong, maka        akan muncul notifikasi agar user melengkapi form terlebih dahulu.
   ![alt text](https://github.com/muhammadyaaqin24-art/UTSWeb_4B_0002/blob/main/pict/pic4.png?raw=true)

3. Dark Mode
   Saya juga menambahkan fitur dark mode menggunakan jQuery. Saat tombol dark mode ditekan, website akan berubah menjadi       tampilan gelap dengan menambahkan class CSS secara otomatis pada halaman website. Fitur ini membuat tampilan website        lebih modern dan nyaman digunakan.
   ![alt text](https://github.com/muhammadyaaqin24-art/UTSWeb_4B_0002/blob/main/pict/pic5.png?raw=true)
